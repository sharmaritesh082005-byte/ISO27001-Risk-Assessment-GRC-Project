# ISO 27001 Information Security Risk Assessment

## Project Overview
This project demonstrates an Information Security Risk Assessment conducted using ISO 27001 principles. The objective was to identify information security risks, evaluate their impact and likelihood, prioritize them through a risk matrix, and recommend appropriate risk treatment actions.

## Objectives
- Identify organizational information assets
- Assess cybersecurity risks
- Create a Risk Register
- Develop a Risk Matrix
- Recommend mitigation controls
- Support compliance and audit readiness

## Key Deliverables
- Risk Register
- Risk Matrix
- Risk Assessment Report
- Risk Treatment Plan
- Audit Support Documentation

## Skills Demonstrated
- Governance, Risk and Compliance (GRC)
- Information Security Risk Management
- ISO 27001 Fundamentals
- Risk Assessment
- Risk Analysis
- Documentation and Reporting

## Tools Used
- Microsoft Excel
- Microsoft Word
- Microsoft PowerPoint

## Outcome
Successfully identified and prioritized information security risks and proposed mitigation strategies aligned with ISO 27001 best practices.
